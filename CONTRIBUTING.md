# Contributing

Thanks for helping! Ideas, button requests and profiles are welcome.

## Ways to contribute

- **Open an issue** describing an Eplan task you would like on a button.
- **Share a profile**: it must be sanitized (see [`docs/sanitizing-checklist.md`](docs/sanitizing-checklist.md)) and include a README listing every button.
- **Share icons**: original work or clearly licensed, with the source stated.

## Rules

- Original work only. No Eplan- or Elgato-owned documentation, training content, or icons.
- No customer, employer or personal data: usernames, machine names, local paths, project names, part numbers.
- Say which Eplan version and Stream Deck software version you tested with.
- Keep a positive, helpful tone.
- By contributing you agree your work is released under the repo's [MIT license](LICENSE).
